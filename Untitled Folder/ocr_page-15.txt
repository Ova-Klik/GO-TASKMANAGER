Milestone 2 — Tasks to Complete

Wire up the database connection, confirm your existing routes still work, then tackle these
tasks:

Task 1 — Update main.go

Load the .env file with godotenv, call config.Load(), and call db.Connect(cfg) before starting the
router.

Task 2 — Add All Routes

Register UpdateTask (PUT) and DeleteTask (DELETE) in routes/routes.go and verify them with
curl.

Task 3 — Add a Due Date

Add a DueDate *time.Time field to the Task model and the input structs. Use go get
github.com/jackc/pgtype if you need extra date types. Re-run AutoMigrate — GORM will add the
column automatically.

Bonus — Pagination

Support ?page=1&limit=10 query parameters in GetTasks. GORM has .Offset(n).Limit(n) — look up
how to calculate offset from page and limit.
