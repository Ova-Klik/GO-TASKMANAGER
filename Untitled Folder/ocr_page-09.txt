Milestone 1 — Tasks to Complete

Complete all the code above so your server runs. Then extend it with these tasks:

Task 1 — Add UpdateTask (PUT /tasks/:id)

Create a handler that replaces a task's title, description, and status. The client sends all fields
in the request body. Return 404 if the task does not exist.

Task 2 — Add DeleteTask (DELETE /tasks/:id)

Create a handler that removes a task from the slice. Return 404 if not found, 204 No Content
on success.

Task 3 — Filter by Status (Query Parameter)
Extend GetTasks to support ?status=pending as a query parameter. If provided, only return tasks
that match that status. Hint: c.Query("status") reads query parameters.

Bonus — Add a PatchTask (PATCH /tasks/-id)

Unlike PUT, PATCH only updates fields the client explicitly sends. A client can change just the
status without touching the title. This is harder — research how to detect zero values in Go.
