1.2 Understanding Gin — Core Concepts

Before writing code, here are the four concepts you will use every Milestone:

Concept What It Means

gin.Engine The heart of your application. Holds all your routes and middleware.
Created with gin.Default() which includes a logger and crash recovery.

Route Handler A Go function with signature func(c *gin.Context). Gin calls this function
when a matching HTTP request arrives.

gin.Context (c) A struct passed to every handler. Use it to read the request (c.Param,
¢.ShouldBindJSON) and write the response (c.JSON, c.String).

Route Groups Lets you share a URL prefix across many routes. r.Group("/api/v1")
means every route inside uses that prefix automatically.

Code to Use It

200 OK Successful GET or PUT/PATCH — return the resource

201 Created Successful POST that created a new resource

204 No Content Successful DELETE — nothing to return

400 Bad Request Client sent malformed JSON or failed validation

401 Unauthorized Missing or invalid authentication token

403 Forbidden Token is valid but user does not own this resource

404 Not Found The requested resource does not exist

422 Unprocessable Entity Request is valid JSON but the values are semantically wrong
500 Internal Server Error Something went wrong on the server — log it and investigate
